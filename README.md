# RutaIA 🎓

> Aplicación web de orientación académica que recomienda cursos a partir de una necesidad escrita en lenguaje natural, usando arquitectura **RAG** (Retrieval-Augmented Generation).

**Proyecto #1 — Campuslands GT · Equipo E2**
**Integrante:** Juan José Pérez Lema

---

## 🚧 Estado

En construcción.

## 🧱 Tecnologías

| Capa | Tecnología |
|---|---|
| Frontend | HTML, CSS, JavaScript (Fetch API) |
| Backend | Java 21 + Spring Boot (Gradle, JPA, Validation, Swagger) |
| Base relacional | MySQL 8.4 |
| Base vectorial | Qdrant |
| Automatización | n8n |
| Embeddings y LLM | OpenRouter |
| Infraestructura | Docker Compose |

## 📁 Estructura del repositorio

```
rutaia/
├── backend/            # API REST con Spring Boot
├── frontend/           # Interfaz web (HTML, CSS, JS)
├── database/           # schema.sql y seed.sql
├── n8n/workflows/      # Flujos exportados de n8n
├── docs/               # Diagramas, colección Postman y pruebas
├── docker-compose.yml
├── .env.example
└── README.md
```
